# YK PRODUCTIONS Website

Professional responsive website for YK PRODUCTIONS.

## Included
- Supplied YK PRODUCTIONS logo (`logo.png`)
- Yadhukrishna PM profile/banner image (`profile.jpg`)
- Responsive professional design
- Phone, WhatsApp, email and Kerala details
- Instagram link decoded from the supplied QR code:
  https://www.instagram.com/_yadhukrishna_pm?utm_source=qr

## GitHub Pages
Create a GitHub repository, upload all files, then go to:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.


## Appointment system
The site includes a client-side appointment form. Submitting it opens WhatsApp
with the visitor's name, phone, service, preferred date/time, and message.
No server or database is required. YK PRODUCTIONS confirms the appointment manually
after receiving the WhatsApp request.

## Formspree email notification
Set the Formspree notification destination to `plaavilla125@gmail.com`.
The appointment form uses the customer's email as the Reply-To address and the subject `New Appointment Request — YK PRODUCTIONS`.


## AJZAL BIRD
The professional YK PRODUCTIONS homepage opens first. Click the AJZAL BIRD service card to open the game, which starts automatically.
The Services section includes an **AJZAL BIRD** card linking to `ajzal-bird/`, a GitHub Pages-ready Flappy Bird-style game.

## Appointment email
Appointment submissions use Formspree and are intended to notify `plaavilla125@gmail.com`. The form uses the visitor's email as Reply-To and does not send appointment requests through WhatsApp.

## JOVAL DINO
A Chrome-Dino-style offline-capable mini game is included at `joval-dino/`. It uses the local `joval-head.png` asset, so the game does not depend on an external image or internet connection while playing.
